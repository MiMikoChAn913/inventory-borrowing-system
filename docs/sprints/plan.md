# Part D - Three-Sprint Plan

| Sprint | Goal and features | Dependencies | Completion outcome |
|---|---|---|---|
| Sprint 1 | Deliver a working authenticated borrowing slice: F-01 through F-06. | PostgreSQL, seed users, React/Express baseline. | Borrower requests; Custodian approves/rejects; Borrower returns; tests and reviewed release on `main`. |
| Sprint 2 | Make operations realistic: F-07 due dates and F-08 custodian-confirmed return. Add defect fixes from partner UAT. | Stable Sprint 1 states and migrations. | Core workflow expanded without breaking previous contracts. |
| Sprint 3 | Add F-09 search/reporting and F-10 audit/product hardening. | Sufficient transaction history, accepted Sprint 2. | Remaining baseline, integration, accessibility, security and release hardening complete. |

Sprint 1 is intentionally a small vertical slice across UI, API and database rather than a collection of disconnected CRUD screens.
